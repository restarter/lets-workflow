# Per-command deep dives

One page per `/lets:*` command, with the full story: what it does, every flag, how the stages work, and the design guarantees behind it. The quick one-table overview lives in [../commands.md](../commands.md) — start there if you just want to pick a command; come here when you want the details of one.

Pages are added over time. Commands without a page here are covered by the quick reference and the topic docs ([workflow](../workflow.md), [plan-execute](../plan-execute.md), [code-review](../code-review.md), [autonomous](../autonomous.md)).
